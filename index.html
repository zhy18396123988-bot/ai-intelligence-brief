Perplexity Agent API 推出托管 Connectors，智能体可直接连接 GitHub 与 Slack

Perplexity 官方文档新增托管连接器预览：管理员可一次配置 GitHub、Slack、Google Drive 和 Datadog，Agent API 通过 connector ID 调用，无需每次传入服务器地址与令牌。

阅读全文与核验记录
背景

MCP 让智能体能调用外部系统，但连接地址、认证与工具发现仍会增加集成成本。托管 Connectors 将这部分配置前移到 API Group 管理层。

适合人群

Agent API 开发者、企业平台团队、需要把代码库、协作消息与监控数据接入智能体的工程负责人。

核心内容
  • 当前支持 GitHub、Slack、Google Drive 和 Datadog。
  • 管理员在 API Portal 连接一次，应用请求中引用 connector ID。
  • GitHub connector 可向 Sandbox 提供凭据，使智能体能够克隆私有仓库、修改代码和创建 PR。
为什么重要

这意味着智能体平台可能从“模型加工具调用”进一步走向托管身份与权限基础设施。对企业而言，集成更快，但预览阶段仍需要重点验证最小权限、审计和凭据边界。
